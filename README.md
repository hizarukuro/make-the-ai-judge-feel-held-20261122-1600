# Make the AI judge feel held

A short text about being held: two hands around a warm mug, nothing asked of the tea, the heat staying a little longer than it has to.

The program is `main.py` (Python 3, standard library only). Run by the grader, it writes the text to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` — 1 to 280 Unicode code points, byte-identical on every run.
